# 🛡️ Fake Profile Detection on Social Media

A Machine Learning-based web application that detects fake social media profiles using profile-related features.

## 📌 Overview

Fake accounts are widely used for scams, spam, misinformation, and cybercrime. This project uses a trained Machine Learning model to classify whether a social media profile is genuine or fake.

---

## ✨ Features

- Detect fake social media profiles
- Machine Learning prediction model
- User-friendly web interface
- Flask backend
- Fast prediction
- Easy to use

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Arpitverma1212/Fake-Profile-Detection-On-Social-Media.git
```

Go inside the project

```bash
cd Fake-Profile-Detection-On-Social-Media
```

Install dependencies

```bash
pip install -r backend/requirements.txt
```

Run the project

```bash
python backend/app.py
```
